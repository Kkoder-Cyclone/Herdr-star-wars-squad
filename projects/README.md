# projects/ — изолированные проекты

Каждый проект живёт в собственной папке (и репозитории): `projects/<project-id>/`.

Правила из скилла herdr-setup:

1. Не смешивай проекты: свой cwd, свои инструкции, свои ветки.
2. auth/state и credentials — внутри штатных профилей CLI, не в папке проекта и не в git.
3. Помощники (режим 2) работают в workspace выбранного проекта, каждый в своей ветке.
4. Тестовые задачи команды — на нейтральной тестовой цели, не на реальном проекте без разрешения.
