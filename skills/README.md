# skills/ — скиллы команды

Сначала проверь «коробку»: у многих CLI дизайн- и браузерные умения уже есть из коробки (Claude Code, Codex, OpenCode поддерживают каталог `skills/` — формат [Agent Skills](https://agentskills.io/specification)). Ставь снаружи только то, чего нет.

## Что обычно уже есть из коробки

| Умение | Где есть |
|---|---|
| Вёрстка и UI-код | Claude Code, Codex, OpenCode (frontend-умения модели + правила AGENTS.md) |
| Браузер/скриншоты | встроенные инструменты или MCP-серверы твоего CLI |
| Git-цикл, ревью | все три CLI штатно |

## Что стоит доставить (дизайн и графика)

| Направление | Что искать | Где |
|---|---|---|
| Дизайн-системы и UI-навык | скиллы `design`, `frontend-design` | [agentskills.io](https://agentskills.io) · каталоги твоего CLI |
| Motion-анимация | скиллы `motion`, `animation` | тот же каталог, топик `agent-skills` |
| Браузер-автоматизация | `browser-use`, Playwright-скиллы | репозитории инструментов твоего CLI |

## Правила установки

1. Читай SKILL.md скилла до установки: источники, зависимости, границы.
2. Клади в штатный каталог скиллов CLI (`~/.claude/skills/…`, `~/.agents/skills/…` и т. п. — таблица в [репо herdr-setup](https://github.com/Kkoder-Cyclone/Herdr-skill-setup)).
3. Не допускай дублей ID. Проверь загрузку в свежей сессии.
